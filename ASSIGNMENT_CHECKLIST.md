# Соответствие заданию

Это указатель на проверяемые материалы, а не прогноз оценки.
Исследование данных охватывает 189 файлов; сравнительные эксперименты детекции
выполнены на заранее выбранных 24 снимках. Полная ручная разметка и обучение
моделей не выполнялись. Четыре группы трактуются как 2 модели × 2 условия:
оригиналы/аугментации, поскольку перечисление групп в предоставленном тексте отсутствует.

| Требование | Где проверять |
|---|---|
| Разрешение, контраст, фон, размеры объектов и перекрытия | Notebook §1; REPORT «Данные»; `results/tables/dataset_inventory.csv`; обзор выборки |
| Не менее четырёх преобразований | Notebook §2; `src/experiment.py::augment`: 6 семейств, 12 вариантов |
| Несколько уровней интенсивности | Яркость, контраст, шум, размытие и гамма по 2 уровня; `augmentation_parameters.json` |
| Визуализация и допустимость аугментаций | 3 галереи; пояснения Notebook §2 и REPORT |
| Одноэтапная и двухэтапная архитектуры | RetinaNet и Faster R-CNN, ResNet-50/FPN v2; Notebook §3, обоснование и различия |
| Предобученные модели, boxes и confidence | Официальные COCO_V1; 624 визуализации; `predictions_*.json`; параметры и SHA256 весов |
| Четыре сопоставимые группы | `detection_four_groups.csv`; 24 одинаковых снимка × 13 вариантов × 2 модели |
| Время, число рамок и устойчивость геометрии | `detection_runs.csv`, `detection_stability.csv`, `detection_by_augmentation.csv`; обратные преобразования координат |
| Пропуски, ложные области, выбор детектора | REPORT «Ошибки и выбор детектора» с конкретными image_id |
| GrabCut из рамок детектора | 5 итераций, без ручных исправлений; `src/segmentation.py` |
| Предобученный SAM 2 с box prompts | SAM 2.1 Hiera Tiny, оригинальный код Meta, без обучения; Notebook §4 |
| Одинаковые подсказки для обоих методов | `segmentation_prompts.json`; проверка `scripts/validate_results.py` |
| Исходные снимки, рамки, маски и наложения | 28 сравнительных панелей; 112 бинарных PNG (рабочее/исходное разрешение); отдельные наложения |
| Фон, тонкие структуры, перекрытия и время | REPORT «GrabCut и SAM 2.1», случаи 000/001/011/016/022/026/027; таблицы сегментации |
| Четыре эксперимента детекции и два метода сегментации в сводной таблице | `results/tables/experiment_comparison.csv`, также в Notebook |
| Успешные и неуспешные случаи, причины | REPORT и 50 встроенных иллюстраций Notebook: шум, контраст, неточная рамка, перекрытия |
| Аргументированный вывод | REPORT «Вывод»; Notebook §5; краткий итог README |
| Notebook с полным кодом и сохранёнными результатами | `plankton_experiments.ipynb`, выполнен без ошибок; HTML для просмотра без Jupyter |
| Воспроизводимость и версии | `requirements.txt`, `requirements-lock.txt`, README, seed, `environment.json`, SHA256 данных/весов |
| Структурированные результаты и организация | CSV/JSON в `results/`; полный комплект изображений в `results_archives/` |
| Просмотр без повторного инференса | Сохранённые выводы Notebook/HTML; обычные ZIP извлекаются `scripts/unpack_results.py` без моделей и сети |
| Права на изображения | Разрешение пользователя зафиксировано в `DATA_POLICY.md`; полный исходный архив не публикуется |

Маски не являются эталонной разметкой. Confidence, число обнаружений,
внутренняя оценка SAM и IoU между двумя методами не используются как точность.
Ручных box prompts нет. Дополнительные случаи перекрытия выбраны после просмотра
и явно отделены от основной схемы эксперимента.
